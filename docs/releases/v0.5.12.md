# claude-peer v0.5.12

A version-alignment release. Its runtime is unchanged from v0.5.10, and its version now matches core v0.5.12. It requires Sessionbus v0.5.9 or newer (daemon and hub) and still pins the Sessionbus Go SDK `v0.5.9`; it does not include Go SDK v0.5.12. Native Claude is installed separately and is not pinned.

`scripts/install-claude.sh` installs the latest stable release by default, so it now installs v0.5.12.

- **Upgrading from v0.5.10** changes no behaviour and needs no daemon, hub or lane-row change.
- **Upgrading from v0.5.9** also brings the v0.5.10 fix; see the [v0.5.10 notes](v0.5.10.md).

## Changes since v0.5.10
- `RELEASE_VERSION` and the Claude plugin manifest (`claude/.claude-plugin/plugin.json`) are 0.5.12.
- **Documentation only:**
  - the development notes describe an isolated, offline probe for re-checking the typed-field and managed-tool guards whenever native Claude's argument grammar changes;
  - the repository now has contributor rules (`AGENTS.md`).
- No runtime, installer, dependency or workflow change.

## Evidence
No new live/native acceptance was run for this release; its runtime is v0.5.10's. The README's installed-validation paragraph describes the earlier field-free validation of a build with the v0.5.9 runtime.
